# 网站界面规则

采用用户最新要求。后来的纠正覆盖早先方案。只应用当前界面涉及的规则。

note 指作者提供的原地说明；批注指读者写给 AI 的反馈。控件术语统一为 link、note、linked note、float panel、tip。

## 视觉

- 使用 1px 极简风格。
- 使用方角和细线。
- 去掉装饰性图标、卡片和视觉噪声。
- 内容图示只用于解释数学或代码。
- 功能按钮使用简洁图标。
- 对称 btn 将上、下两个矩形点击区合为一个标准按钮大小，icon 始终居中；透明底的小数字角标贴于 icon 本体，不改变其位置，只显示当前段落序号；共用 tip 保留操作与当前段落位置、总数。
- 字体风格统一。
- 正文使用清晰的中文字体。
- 代码、路径和版本号使用协调的等宽字体。
- 优先压缩间距，不随意缩小字号。
- 目录尽量紧凑。
- 间距使用少量一致的尺度。
- 对齐标题、工具栏、代码和面板内边距。
- 不用无谓的留白制造层次。

## 页面与顶部

- 博客拥有内容与站点配置，框架只提供通用渲染与交互；文章不要求关联代码仓库。
- 关联仓库的文章按仓库版本保留一份 MDX，按 H1 生成逻辑文章页。
- 目录使用真实链接加载对应 H1 的正文，H2–H6 在所属页内定位；不下载整篇后仅隐藏内容。
- H1–H6 自动链接到自身，保留原文字与行内格式；右上角显示小 #，标题及标记不加下划线。
- 顶部栏铺满页面宽度。
- 限制中央 MDX 内容面板宽度，不限制整个页面宽度。
- 正文在中央集中排布。
- 目录不能挤占正文，也不能贴住正文。
- 本项目正文面板默认最大 720px，目录默认 220px。
- 关联仓库时，顶部保留仓库名与提交号；独立文章使用博客身份。
- 仓库名与文章 H1 分别表达仓库身份和文章标题。
- 不在顶部增加章节导航。
- 有左侧目录时，不再增加面包屑。
- 顶部滚动固定时使用磨砂背景。
- 返回按钮只放左上角。
- 不在底部重复返回按钮。
- 黑白主题切换放右上角。
- 批注模式按钮放右上角。
- 使用正常链接跳转，不设计花哨的过渡或路由。

## 主题与控件

- 黑白主题保持相同的结构、尺寸和状态规则。
- 用纸面、正文、次文、边框和选中块建立层次。
- 两种主题的相对对比度应协调。
- 调整一个主题时，保留用户认可的另一主题。
- 控件图标使用统一的前景色和线宽。
- tip 共用一个组件、样式与定位规则；不混用浏览器原生 title 提示。
- tip 只补充操作或隐藏信息，不复述控件已有的文字、当前值与状态。
- 明确的通用动作复用同一 tip；有歧义时保留必要的操作对象，避免过度缩写。
- 自动聚焦不触发 tip。
- 焦点框使用 focus-visible；鼠标点击不残留焦点框。
- 不混用浏览器原生控件皮肤。
- 悬停和选中时，染满按钮自身背景。
- 不把按钮高亮扩展成无关的整行。
- 选中与悬停的灰度服从当前主题。
- 文本选区使用灰色反色。
- 深色主题被选文字使用足够深的黑色。
- 文本选区不能继续使用浏览器默认蓝色。
- 全局 scroll 可见滑块为 4px，原生命中范围为 8px；以透明边缘扩展命中，不另写拖动逻辑。
- 滚动条仅在内容溢出且 hover 时显示，拖动期间保持可见；全站共用规则。
- 拖拽分隔条默认隐藏。
- 分隔条只在悬停、键盘聚焦或拖拽时显示。
- 显示的分隔条统一为 4px。
- 分隔条保留足够的命中区域，不显示 tip。
- 目录与文件双栏共用分隔条样式和状态逻辑。
- 数字输入框保持同一套极简控件样式。

## 版本与目录

- 提交号是可展开的版本选择器。
- 只有一个版本时也允许展开。
- 每个仓库允许多个版本和多份 MDX。
- 版本选择使用真实页面链接。
- 下拉菜单与触发器等宽，边缘按 1px 对齐。
- 下拉项使用统一的整块背景高亮。
- 两侧 tree 共用 1px 连接线规则与间距变量；本项目横向缩进 8px、图标与名称间距 2px，节点纵向不留额外间隙。
- 展开按钮与横向支线对齐文本首行，不随多行名称垂直居中。
- 横线左端接入竖线，父子分支连续衔接；竖线在最后一个分支处收口，不留断缝或穿线。
- 同级文件与文件夹名称对齐；文件保留展开按钮列的空位，不改变行高。
- 目录直接读取 MDX 的 H1–H6。
- 完整保留标题文本、编号和层级。
- H1 必须出现在目录中。
- 不另写目录标题，不改简称，不私自重排层级。
- 整个目录可以收起。
- 两侧栏的关闭状态在首屏样式应用前恢复，避免刷新时先显示后隐藏；共用状态逻辑。
- 树形分支可以独立收起。
- 仓库名与展开 icon 合为一个 button，点击只展开或收起；文章标题保留 link 跳转。
- 允许拖拽目录宽度。
- 双击目录分隔条恢复默认宽度。
- 目录宽度不能破坏中央正文的阅读位置。

## 文件浏览与代码分布

- 右侧文件树对应当前仓库的选定 commit；点击文件复用 inline code viewer。
- 指向可独立访问目标的入口使用带真实 href 的原生 link，保留浏览器 URL 提示、复制链接及新标签打开；复制、关闭、折叠和单纯调整尺寸使用 button。
- 完整目录载入后从内存索引展开分支，不逐层请求目录。
- “代码分布”按本仓存在的后缀选择；无后缀项显示文件名，选择“无”清除分布。
- 分布只画名称下方的 1px 线，以该项占上级目录同后缀行数的比例计；线从名称列起笔，避开展开按钮和树干。
- 名称截断，或已开启分布且行数大于零，满足任一条件才显示 tip；完整路径仅在名称截断时显示，统计使用 `1.33K行 30%`，不增加常驻数值或上级目录说明。
- 关闭 inline code viewer 保留文件项选中填充；后续点击文件项外的页面区域再清除。关闭按钮与 Esc 行为一致。
- 文件与文件夹共用点击焦点填充和失焦规则；展开状态不等同于焦点。
- 按仓库和 commit 保存展开分支、分布选择、未关闭的文件及其标注；刷新恢复，关闭后的文件不因刷新重开。

## 代码与文件组件

- 文件列表做成可嵌入 MDX 的组件。
- 文件列表和代码区支持灵活分栏。
- 允许调整两栏宽度和组件高度。
- 右侧代码独立横向、纵向滚动。
- 代码块支持滚动与非滚动配置。
- 所有代码块标明语言。
- 所有代码使用彩色语法渲染。
- 代码块与 inline code viewer 共用换行、复制控件和状态逻辑；代码块保留右侧展开入口，viewer 保留右侧关闭按钮。
- 换行使用两态图标与整块选中背景，只改变排版；复制保留原始文本，不包含行号或软换行。
- 滚动代码的语言和工具栏使用磨砂背景。
- 工具栏不能覆盖滚动条或拖拽命中区。
- 验证滚动条拖拽，不只验证滚轮滚动。
- 展开使用方框向外扩张图标，不使用四角箭头。
- 本文代码块展开与非本文文件查看统一使用 inline code viewer (float panel)。
- CodeBlock 的内容来源、正文可见性与标注彼此独立；`code` 与 `src` 二选一，`render={false}` 保留可引用的隐藏定义。
- `.md`、`.mdx` 在 CodeBlock 与 inline code viewer 中默认显示文档；title 的源码 icon button 切换文档和源码，复用文章解析、公式、高亮、heading tree 与 H1 分页，不为临时文件另写解析规则。
- 内嵌代码与 src 文件共用结构化 `notes / links / marks` 定位和渲染，不另设 URL 标注解析器；保持 Shiki token 与原始代码不变。
- 共用标题、行号、渲染、滚动和关闭逻辑。
- 展开后的标题文字和样式沿用原代码块。
- 源码全文也必须语法高亮。
- inline code viewer 始终显示行号；行号不进入选区或复制内容。
- inline code viewer 面板自身不透明。
- 只对浮窗外侧背景做磨砂。
- inline code viewer 默认 modal，使用磨砂背景并锁定正文滚动；页面 title 仍可操作。
- 点击磨砂背景将最上层 modal viewer 转为 non-modal，保留其他面板；viewer 关闭使用图标或 Esc，临时 note 和批注编辑框仍遵守外部点击关闭规则。
- 拖动 viewer 标题栏转为 non-modal，保持内容、滚动位置和拖放位置；页面恢复可操作，面板保留到关闭按钮或 Esc 关闭。
- 拖拽点不能越过页面 title 下沿；保留抓取偏移，窗口自身可部分越过 title，不按窗口边缘回弹。
- viewer 最大宽高与 modal 共用上限，滚轮和右下角 resize 使用相同限制。
- viewer 标题栏滚轮向上放大、向下缩小，沿用 non-modal resize；Ctrl/Meta 滚轮保留浏览器缩放。
- non-modal viewer 支持右下角双向 resize，最小高度只留标题栏，双击 resize 区域最小化或还原高度；保留宽度、位置与代码滚动状态，modal 状态不显示 resize。
- 双击 viewer 标题栏在居中 modal 与上一次 non-modal 的位置、尺寸间切换；首次采用原始位置，复用同一内容与滚动位置，URL 随模式同步。
- viewer 标题栏使用普通箭头指针，拖动时也不用抓手；功能图标保持可点击指针。
- 行高亮共用代码画布的完整宽度，resize 和横向滚动后保持连续；软换行时画布随可视宽度收敛。
- viewer 只要有 lines 标记就保留上一段、下一段按钮；单段也能回到该段起点，多段首尾循环，无须重绘代码或修改 URL。
- 浮层内滚动不传给背景；note 与批注编辑框允许框外操作页面。
- 浮窗关闭后保持原阅读位置和页面宽度。
- 短内容浮窗按内容收敛，长内容限制高度并保留屏幕上下留白。
- 关闭按钮保持图标风格。
- 浮窗不再放“固定提交”按钮。

## link 与 note

- link 与 note 独立组合。
- note 直接附于原文，不使用 numbered note。
- 下划线共用 1px 低亮度颜色；hover 只改变虚实，不提亮。
- link：实线下划线，点击跳转。
- link 右上角以 `↗` 标记站外跳转、`→` 标记站内跨页面；同页锚点和当前页内的文件浮窗不标记。标记共用组件，不进入复制文本。
- note：虚线下划线，hover 变实线，点击固定 float panel。
- linked note：实线下划线，hover 显示 float panel，点击跳转。
- inline code viewer 的结构化标注复用同一套 link、note、linked note 交互；linked note 是同范围 link 与 note 的组合。
- 所有 note 在 hover 或 focus 时显示简短说明，共用一个 float panel。
- 点击任意已显示的 float panel 都能固定。
- 固定后，选字、失焦或移出不关闭。
- Alt 暂停新的 note hover，并临时保留已显示的未固定 float panel；松开按当前位置重新检测，不改变固定状态。
- float panel 共用 layer 管理；点击 layer=z 只关闭 layer>z 的临时 panel，不因更高层交互关闭低层 panel；保留的 non-modal viewer 不随背景点击关闭。
- 页面与目录为 layer 0；title 为最高层且不可关闭；从 panel 打开的编辑 panel 位于其前方。
- Esc 优先交给浏览器原生 UI，不因焦点回到页面而抢先或同时关闭 FP；原生关闭操作结束后，保留最上层 FP 的 Esc 关闭，不退出批注模式。
- 交叠范围在 MDX 中拆成相邻片段，不做自动范围识别或嵌套交叠控件。
- 保留 KaTeX 排版与代码高亮。

## float panel URL

- URL-capable float panel 使用固定类型名；当前 inline code viewer 对应 `code`。新增类型时一起定义名称、参数校验与恢复行为。
- 作者链接使用 `?fp=code&block=代码块ID`；src、行范围及标注由 MDX 定义，URL 只引用 block，不重复携带配置。
- 临时文件浏览使用 `?fp=code&file=src/a.cpp&lines=10-20`；file 与 block 互斥，lines 可省略，block 的行范围属于定义。
- 多个使用一个 Rison 数组：`?fp=!((type:code,block:a),(type:code,block:b))`；每项也可独立使用 file 与 lines，不使用数字参数前缀，不混用平铺属性。
- URL 只记录 modal 面板，数组顺序由后向前决定层级；每项独立加载与关闭，不互相覆盖。
- viewer 转为 non-modal 时只移除它的 URL 与刷新恢复记录，剩余面板重新编码；面板本身不关闭、不重新加载。
- 复制链接、刷新和前进后退保留面板配置；关闭后同步 URL，剩一个时恢复单个形式，全部关闭后移除 fp 参数。
- URL 编解码、类型注册与层级管理共用实现；各类型只负责自己的参数和内容。
- block 定义在仓库版本内唯一，跨 H1 按需加载；多实例共享定义与资源缓存，各自保留面板状态。

## 读者批注

- 批注模式按钮简短提示选字、Alt 与 Ctrl 拖拽截图。
- 普通文本选择用于文字批注。
- Alt 选字只选择文本，不打开批注编辑框，松开也不补开。
- 图片区域只能通过按住 Ctrl 拖拽框选。
- 先选文字，再进入批注模式，也要立即打开编辑框。
- 批注编辑框贴近选区，保持原文可见。
- 不使用固定居中的批注大弹窗。
- 批注编辑框使用细边框和磨砂背景。
- 普通选择、跨区域选择与批注编辑共用同一种高亮和范围，输入时不夺取焦点。
- 保留原框选区域，不再显示重复的图片预览。
- 截取状态只用确认图标的不可用状态表达，不增加进度文字。
- 用勾选按钮确认并复制。
- 文字批注复制为纯字符串。
- 字符串包含文章、仓库版本、原始章节、MDX 位置、原文和批注。
- 图片批注复制为单张完整图片。
- 图片上方保留原选区，下方增加空白底的定位信息和批注。
- 图片文字大小适中，支持换行。
- Esc 仅取消当前编辑或框选。
- Esc 不退出批注模式。
- 退出批注模式只通过模式按钮。

## 迭代

- 尽早提供可操作的 UI 预览。
- 让用户直接调整，不先做大套装饰页面。
- 同时检查默认、悬停、选中、展开和关闭状态。
- 同时检查黑白两种主题。
- 全局 UI 重构时，用独立子 agent 审查间距和风格一致性。
- 修复一个控件时，检查同类控件是否共用实现。
- 不以视觉相似代替组件和代码上的统一。
